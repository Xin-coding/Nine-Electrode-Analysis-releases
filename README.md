# Nine Electrode Analysis — Downloads

[下载安装包 / Download installers](https://github.com/Xin-coding/Nine-Electrode-Analysis-releases/releases/latest)

Windows 64 位九电极离线分析程序，支持 TDMS / log 时间对齐、手动实验区间、可编辑公式、电位参比换算、功率核算与 GC 法拉第效率。界面支持中文和 English。

安装包不嵌入 MATLAB Runtime；首次安装按需从 MathWorks 下载免费的 R2025a Runtime。无需 MATLAB 许可或 Microsoft Excel。具体操作与离线安装方式见各版本附带的 INSTALL.md。

Windows 64-bit offline analysis for nine-electrode experiments: aligned TDMS/log recordings, manual experiment intervals, editable formulas, potential scales, power balance and GC Faradaic efficiency. Chinese and English interface.

The installer downloads free MATLAB Runtime R2025a separately when needed. Neither a MATLAB license nor Microsoft Excel is required. Installation and offline-use instructions are included with each release.

This repository contains installers and documentation only. Application source is maintained privately; experimental recordings and user configurations are not distributed.
